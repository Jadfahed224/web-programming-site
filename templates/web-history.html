History of the Web

Introduction

The Web is a service that runs on top of the internet and it is a collection of digital pages stored on computers across the world and it can be accessed over the internet by using a browser.

Key Milestones

    1989 - The Web is proposed

    Tim Berners-Lee proposed a global hypertext system at CERN. This became the starting point for the World Wide Web.

    Source: CERN - A Short History of the Web

    1990 - First Web browser and server

    Berners-Lee created the first Web browser/editor and Web server. The Web became a working system.

    Source: CERN - Where the Web Was Born

    1991 - Web becomes available beyond CERN

    The Web software was made available beyond CERN. Other researchers could begin using and developing the Web.

    Source: CERN - A Short History of the Web

    1993 - Web enters the public domain

    CERN made the Web software available without licensing fees, helping the Web spread more widely.

    Source: CERN - Where the Web Was Born

    1993 - Mosaic browser released

    NCSA released the Mosaic browser. Its user-friendly design and support for images helped make the Web more popular.

    Source: NCSA - NCSA Mosaic

    1994 - W3C is founded

    Tim Berners-Lee founded the World Wide Web Consortium (W3C). It helped develop common Web standards.

    Source: W3C - History

    1995 - JavaScript is introduced

    JavaScript was introduced in Netscape Navigator 2.0, adding scripting and interactive behavior to Web pages.

    Source: MDN - JavaScript History

    1996 - CSS1 becomes a Web standard

    CSS1 became a W3C Recommendation, providing a standard way to control the presentation and style of Web pages.

    Source: W3C - CSS1 Recommendation

    1997 - HTML 4.0 is released

    HTML 4.0 became a W3C Recommendation and introduced important improvements for structuring Web documents.

    Source: W3C - HTML 4.0 Recommendation

    2004 - Web 2.0 emerges

    The Web 2.0 concept gained attention through the Web 2.0 Conference, emphasizing the Web as a platform for participation and collaboration.

    Source: O'Reilly Media - Tim O'Reilly Biography

    2008 - HTML5 development advances

    HTML5 development progressed through W3C work, providing new capabilities for modern Web applications.

    Source: W3C - HTML5 History

    2014 - HTML5 becomes a W3C Recommendation

    HTML5 became a W3C Recommendation, establishing a major standard for modern Web development.

    Source: W3C - HTML5 History

    2015 - The Web moves toward secure communication

    W3C promoted secure communication and encouraged the use of HTTPS instead of unencrypted HTTP.

    Source: W3C - Securing the Web

    2017 - WebAssembly Working Group is formed

    The W3C WebAssembly Working Group was formed to standardize a fast and efficient execution environment for Web applications.

    Source: W3C - WebAssembly Working Group Charter

    2019 - WebAssembly 1.0 becomes a W3C Recommendation

    WebAssembly 1.0 became a W3C Recommendation, providing a standard way to run high-performance code on the Web.

    Source: W3C - WebAssembly Core Specification

    2021 - WebRTC becomes a W3C Recommendation

    WebRTC became a W3C Recommendation, standardizing real-time communication features such as audio, video, and data exchange in Web applications.

    Source: W3C - WebRTC History

    2026 - HTML continues as a Living Standard

    HTML continues to evolve as a Living Standard maintained by the WHATWG, allowing the Web platform to develop continuously.

    Source: WHATWG - HTML Living Standard

3 Key Technologies

  1. HTML (Hypertext Markup Language):

    A language used to structure Web pages and create links between information.

  2. HTTP (Hypertext Transfer Protocol):

    A protocol that allows Web browsers and servers to communicate and exchange Web resources.

  3. URL (Uniform Resource Locator):

    An address used to identify and locate resources on the Web.
