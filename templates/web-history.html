Introduction

The Web is a service that runs on top of the internet and it is a collection of digital pages stored on computers across the world and it can be accessed over the internet by using a browser.

Key Milestones

  • 1989 - The Web is proposed: Tim Berners-Lee proposed a global hypertext system at CERN. This became the starting point for the World Wide Web.
  • 1990 - First Web browser and server: Berners-Lee created the first Web browser/editor and Web server. The Web became a working system.
  • 1991 - Web becomes available beyond CERN: The Web software was made available on the Internet. Other researchers could begin using and developing the Web.
  • 1993 - Web enters the public domain: CERN made the Web software available without licensing fees, helping the Web spread more widely.
  • 1993 - Mosaic browser released: NCSA released the Mosaic browser. Its user-friendly interface helped make the Web more popular and easier to use.
  • 1994 - W3C is founded: Tim Berners-Lee founded the World Wide Web Consortium (W3C). It helped develop common Web standards so websites and browsers could work consistently.

3 Key Technologies

  1. HTML (Hypertext Markup Language): A language used to structure Web pages and create links between information.
  2. HTTP (Hypertext Transfer Protocol): A protocol that allows Web browsers and servers to communicate and exchange Web resources.
  3. URL (Uniform Resource Locator): An address used to identify and locate resources on the Web.
