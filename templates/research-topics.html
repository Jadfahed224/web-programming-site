Research Topics

This page contains a collection of research topics related to web programming. Each topic covers a different concept and provides useful information about its role in web development.

1. CSS At-Rules

CSS at-rules are special CSS instructions that begin with the @ symbol. They control specific behaviors such as responsive design, animations, fonts, and stylesheet organization.

Main At-Rules

  • @charset: Defines the character encoding of a stylesheet.
  • @color-profile: Defines a color profile for advanced color management.
  • @container: Applies styles based on the size or conditions of a container.
  • @counter-style: Creates custom list numbering and bullet styles.
  • @custom-media: Defines reusable media query conditions.
  • @document: Applies styles based on document URLs; it is deprecated and non-standard.
  • @font-face: Loads and defines custom fonts.
  • @font-feature-values: Defines names for special font features.
  • @font-palette-values: Defines color palettes for color fonts.
  • @function: Defines reusable custom CSS functions.
  • @import: Imports another CSS stylesheet.
  • @keyframes: Defines the stages of CSS animations.
  • @layer: Organizes CSS into cascade layers.
  • @media: Applies styles when specific conditions, such as screen size, are met.
  • @namespace: Defines XML namespaces for CSS selectors.
  • @page: Controls the layout of printed pages.
  • @position-try: Defines fallback positions for positioned elements.
  • @property: Defines the behavior and syntax of a CSS custom property.
  • @scope: Limits styles to a specific part of a document.
  • @starting-style: Defines starting styles for elements entering the page.
  • @supports: Applies styles when a browser supports a specific CSS feature.
  • @view-transition: Controls transitions between webpage views.

2. <button> vs <input type="button">

Both elements can create a clickable button, but they are not identical.

<button>

The <button> element is a dedicated HTML button element. It can contain text and other HTML content such as images or icons. Its type can be submit, reset, or button.

<button type="button">Click Me</button>

<input type="button">

The <input type="button"> element creates a button with no default action. Its label is provided through the value attribute.

<input type="button" value="Click Me">

Main Difference

The <button> element is more flexible because it can contain HTML content. The <input type="button"> element is simpler and uses the value attribute as its label.

3. <datalist> vs <select>

Both elements can provide users with a list of options, but they work differently.

<datalist>

The <datalist> element provides a list of suggested values for an associated <input>. The user can choose a suggestion or enter another value that is not in the list.

<label for="browser">Choose a browser:</label>
<input list="browsers" id="browser">

<datalist id="browsers">
    <option value="Chrome">
    <option value="Firefox">
    <option value="Edge">
</datalist>

<select>

The <select> element creates a control containing a list of options. The user selects an available option from the list.

<label for="browser">Choose a browser:</label>

<select id="browser">
    <option>Chrome</option>
    <option>Firefox</option>
    <option>Edge</option>
</select>

Main Difference

<datalist> provides suggestions while still allowing the user to enter a different value. <select> provides a defined list of choices that the user selects from.

4. JavaScript, JScript, ECMAScript + Automatic Call for a Function

JavaScript

JavaScript is a programming language used to make webpages interactive and dynamic. It is mainly used in web browsers but can also run in other environments such as Node.js.

JScript

JScript was Microsoft's implementation of the ECMAScript scripting language. It was mainly used with Microsoft technologies such as Internet Explorer and is now considered a legacy technology.

ECMAScript

ECMAScript is the standardized specification that defines the core language used by JavaScript. It is maintained by Ecma International through the TC39 committee and is defined in the ECMA-262 standard.

Main Difference

  • JavaScript: The widely used name for the programming language.
  • JScript: Microsoft's historical implementation of the ECMAScript standard.
  • ECMAScript: The standardized specification that defines the core language.

Automatic Call for a Function

A function normally runs when it is called.

function hello() {
    console.log("Hello");
}

hello();

JavaScript also allows a function to be created and called immediately. This is called an Immediately Invoked Function Expression (IIFE).

(function () {
    console.log("Hello");
})();

The function is executed immediately after it is defined. IIFEs are useful for creating a separate scope for variables and preventing unnecessary global variables.
